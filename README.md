# AJAX: GET → POST

Учебное задание с `db.json` из архива `l27-db.zip`.

## Запуск

```sh
npm start
```

Откройте http://127.0.0.1:3000. Страницу нужно открывать через HTTP:
при открытии `index.html` как локального файла браузер может запретить чтение JSON.
Зависимости устанавливать не нужно.

При загрузке страницы `getData('./db.json')` получает объект. Только после
успешного получения `sendData` отправляет **тот же объект** POST-запросом на
`https://jsonplaceholder.typicode.com/posts`. Результат или понятная ошибка
показываются на странице. При ошибке GET POST не выполняется.

JSONPlaceholder — тестовый сервис: он возвращает ответ с `id`, но не сохраняет
запись на сервере. Для POST требуется доступ к интернету.

Проверки: `npm test`.
